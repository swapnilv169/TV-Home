# Planned work

## After 1.9: remote button mapping

Explore phone-configured mappings for remote buttons, such as opening a chosen IPTV app from Live TV or opening supported settings. Targeted for 2.0 investigation, not included in 1.9. Fire OS may reserve buttons or suppress their events; unrestricted remapping cannot be promised. Existing Home, sleep, wake and power behavior needs separate regression testing before any change.

## Deferred ideas

- Optional music/lyrics screensaver, inspired by [Idiot Box](https://github.com/da-r-k/idiot-box). Revisit only after core reliability and memory cost are established.
- A separately profiled virtualized app library for unusually large catalogs.

The playback widget and PiP support are not included. These notes are plans, not announced release features or delivery dates.
